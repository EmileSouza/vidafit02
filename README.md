# vidafit02

Aplicativo mobile para gestão de rotina fitness: treinos, nutrição e hidratação. Desenvolvido com foco em performance, UX e sincronização em nuvem.

## Começar

1. Instale as dependências

   ```bash
   npm install
   ```

2. Inicie o app

   ```bash
   npx expo start
   ```

## Tecnologias

- [Expo](https://expo.dev) / React Native
- Firebase (autenticação e sincronização em nuvem)
